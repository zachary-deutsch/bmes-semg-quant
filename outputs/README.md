# Verification output

`synthetic_verified.json` is generated by the final operational package, using `configs/synthetic.json`. It is **synthetic functionality evidence only, not poster results**. Signals are generated in memory and are not saved.

The JSON contains actual per-subject, per-resample scores, split keys, feature counts, timings, and package versions. Shared transform timing fields are repeated for both classifiers for traceability and should be counted once per subject/resample. Runtime values vary by machine/run. Ridge alpha=1 is an illustrative choice, not a recovered paper setting.

All other outputs are ignored by Git by default. New runs use unique output filenames unless an explicit path is supplied. Existing files are not overwritten. No trained model is persisted.
